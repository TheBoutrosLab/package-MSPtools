# Bundled cRAP snapshot

`crap.fasta` contains 116 GPM common Repository of Adventitious Proteins
(cRAP) entries, including laboratory contaminants and protein standards.

- Original project: https://thegpm.org/crap/index.html
- Original download: ftp://ftp.thegpm.org/fasta/cRAP/crap.fasta
- Archived source: https://zenodo.org/records/15115102/files/crap_gpm.fasta
- Archive: Laurent Gatto, *Proteomics contaminant databases*, version 1.0,
  https://doi.org/10.5281/zenodo.15115102 (CC BY 4.0).
- Compiled by the GPM organization; archived via Charlotte Dawson's camprotR
  collection and Laurent Gatto's MsDataHub data collection.
- Retrieved: 2026-11-19. Original bytes and headers are preserved.
- MD5: `c1640d4054ec771d05c6f4493307f29f`
- SHA256: `4b0e6e97ab1d618baa38be612a787d884a781e07f627b919c4b29ac064db5382`

This fixed snapshot ships with MSPtools; the command requires no network access.
